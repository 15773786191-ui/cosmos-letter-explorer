# Shared continuous world exploration

The galaxy homepage embeds Saturn's accepted v11 preview and a shared explorer for Mercury, Venus, Moon, Mars, Jupiter, Uranus, Neptune and Sun. The v23 same-origin entry handshake loads the embedded renderer first, retains the texture spin phase, and matches projected model position, radius and orientation before the parent camera flight ends. A short dissolve reveals controls. Back transfers the current projection before restoring the original galaxy scene. The parent renderer is suspended while the embedded scene is active.

Each of the eight additional worlds has nine topics: overview, terrain or outer atmosphere, weather/environment, poles/axis, interior, Earth comparison and three interior layer topics. Cards display direct descriptions, mechanisms and comparisons; no quizzes, category menu, discovery ledger or More Detail controls. Desktop and mobile keep a small scrolling information card over a full-size scene. The title and close button share a row; the source link is aligned with the final note.

Wheel, pinch and slider smoothly approach the existing sphere. Drag pans; a visible toggle enables rotation. Markers for specific parts attach to visible model points, use connected endpoints and avoid the card. Terrain/weather theme entries carry “了解” and omit geographic leader lines; they identify feature classes, not named geographical sites or verified geographic coordinates. The generic planet texture is a finite-resolution appearance model. It is not a measured ground-level terrain mesh. The shared v22 material provides consistent neutral teaching illumination in overview and close-up. Neptune, Uranus and Venus palettes are natural-color appearance estimates, not calibrated photographs. Sun granulation, cross-section colours and layer boundaries are explicit teaching schematics; qualitative interior radii differ by world.

The default small Earth is a comparison-entry model. Selecting it transitions to the stated diameter ratio and a common-hours rotation comparison; default thumbnails are not to scale. Self-rotation outside that comparison is decorative and accelerated. Sun rotation comparison uses a representative equatorial period. Venus/Uranus axial orientation represents their retrograde rotation.

Knowledge sources are linked per world to NASA facts. Local planet textures retain Solar System Scope CC BY 4.0 attribution in galaxy-preview/ASSET-CREDITS.md.
